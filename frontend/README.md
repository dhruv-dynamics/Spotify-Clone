# Spotify Clone - Frontend

This is the client-side single-page application for the Spotify Clone, developed by **Dhruv**.

## Tech Stack
- **React 18** with **Vite**
- **Redux** & **Redux-Thunk** for state management
- **Tailwind CSS** for responsive Spotify dark styling
- **React Router v6** for client routing
- **React Toastify** for notification alerts

## Scripts
- `npm run dev` - Start local development server on `http://localhost:3000`
- `npm run build` - Build production bundle
- `npm run preview` - Preview production build locally
